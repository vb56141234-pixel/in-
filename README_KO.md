# 1028FALL Studio

사진 폴더를 인스타그램용 정사각형 이미지와 캡션으로 만드는 로컬 웹앱입니다. Node나 관리자 권한이 필요하지 않습니다. AI 없이도 제목·본문을 직접 넣고 PNG/ZIP을 만들 수 있습니다.

## 1. 준비

1. 이 프로그램의 ZIP을 **완전히 압축 해제**하세요. ZIP 안에서 실행하지 마세요.
2. Windows 10/11에 Python **3.10 이상**을 설치하세요. <https://www.python.org/downloads/>
3. 설치 화면에서 **Add python.exe to PATH**를 선택하세요.
4. 최초 설치와 실행기의 의존성 확인에는 인터넷이 필요합니다. 한글과 공백이 있는 로컬 폴더를 사용할 수 있도록 구현했습니다. 동기화 중인 OneDrive 폴더보다 일반 로컬 폴더를 권장합니다.

## 2. 실행

`START_HERE.cmd`를 더블클릭하세요. `.venv` 생성과 패키지 설치 후 브라우저가 열립니다. 콘솔 창은 앱을 실행하는 동안 열어 두세요. 종료는 콘솔에서 **Ctrl+C**입니다. 브라우저를 닫아도 서버는 종료되지 않습니다.

브라우저가 열리지 않으면 콘솔에 표시된 주소를 직접 입력하세요. 기본 포트는 8765이며 사용 중이면 8795까지 자동 탐색합니다. Windows 실행은 아직 실제 Windows 장비에서 검증하지 않았습니다. 아래 테스트 범위를 확인하세요.

## 3. API 키 설정

최초 실행으로 설치를 마친 뒤 앱을 종료하고 `setup_api_key.cmd`를 더블클릭하세요. 키는 입력 중 표시되지 않고 이 폴더의 `.env`에 저장됩니다. 앱을 다시 실행해야 적용됩니다. 키를 문서·사진·채팅에 붙여 넣지 마세요.

OpenAI API는 별도 사용 요금이 발생할 수 있습니다. 기본 모델은 `gpt-4.1-mini`이며 `.env`의 `OPENAI_MODEL`로 변경할 수 있습니다. 브라우저에는 키가 전달되지 않습니다. 키가 없으면 데모 모드에서 AI 기능만 비활성화됩니다.

## 4. 사진 업로드

**폴더 업로드** 또는 **이미지 파일 선택**을 누르세요. JPG/JPEG/PNG/WEBP를 지원합니다. 100장 이상도 순차 업로드하며 한 파일 최대 32MB, 최대 4천만 픽셀입니다. 지원하지 않는 파일은 건너뛰고 손상된 사진은 오류로 안내합니다. 브라우저 폴더 업로드 권한 안내가 나오면 선택한 폴더만 허용하세요.

## 5. 이미지 생성

언어, 로고(PNG/WEBP), 문체 샘플을 설정하고 **⚡ 1:1 이미지 순차 변환**을 누르세요. 이 버튼 또는 **↻ 재생성**을 누를 때만 사진을 OpenAI에 전송합니다. AI는 이미지 분석 후 선택한 언어로 제목과 캡션을 만듭니다. 오류는 카드별로 표시되고 다음 사진으로 계속 진행합니다. 기존 문구는 재생성이 성공할 때까지 유지됩니다. 중지는 현재 이미지의 요청 완료 후 적용됩니다.

AI 없이 사용하려면 **직접 넣기**를 누르고 제목과 본문을 입력하세요. 이미지가 자동 합성됩니다. 스타일 패널에서 위치·크기·굵기·그라데이션·로고 위치를 조정할 수 있습니다. 정사각형 합성은 중앙 crop이며 원본 비율을 유지합니다. 긴 제목은 줄바꿈과 자동 축소를 적용합니다. Bold 폰트만 있는 시스템에서는 ExBold/Black을 가장 가까운 굵기와 외곽선으로 표현합니다.

한글과 일본어에 시스템 폰트를 사용합니다. Windows에서는 맑은 고딕 Bold를 우선 사용합니다. 특정 글자가 깨지면 해당 언어 폰트가 설치되어 있는지 확인하세요. 필요하면 `.env`에 `STUDIO_FONT="C:/경로/폰트.ttf"`를 설정하고 재실행하세요. 폰트 파일은 프로그램에 포함하지 않습니다.

## 6. 결과 저장

- **PNG 직접 저장**: 해당 카드의 1080×1080 PNG를 받습니다.
- **COPY**: 편집한 본문을 복사합니다.
- **전체 ZIP 다운로드**: `images/`, `sources/`(원본), `captions.txt`, `captions.json`, `project.json`, 업로드한 `logo.png`를 저장합니다.
- **프로젝트 JSON**: 편집 설정만 따로 저장합니다. 원본까지 보관하려면 ZIP을 사용하세요.

캡션 JSON은 이미지별 원본 파일명, 생성 언어, 제목, 본문을 포함합니다. 프로젝트는 제목 위치·폰트·로고 위치·그라데이션 설정까지 포함합니다. **프로젝트 ZIP 불러오기**로 저장한 ZIP의 원본·제목·본문·스타일·로고를 다시 열 수 있습니다. 최대 512MB(압축 해제 기준), 1000장까지 지원합니다. JSON만으로는 사진이 복원되지 않으므로 ZIP을 보관하세요.

사진과 작업 내용은 `data/temp/`에 로컬 저장됩니다. 같은 브라우저 세션에서 새로고침하면 유지되지만 앱을 재시작하면 새 세션이므로 복원되지 않습니다. 종료 전에 ZIP을 받으세요. **목록 비우기 · 임시파일 정리**는 현재 작업의 사진·로고·렌더·내보내기 파일을 지웁니다. 이전 세션 파일까지 정리하려면 앱을 종료하고 `data/temp` 폴더를 삭제하세요. 프로젝트 불러오기 이전의 파일도 이 정리 방법으로 삭제할 수 있습니다. 사진의 외부 전송은 AI 작업 때만 발생합니다.

## 7. 오류 해결

### Python을 찾을 수 없습니다
Python 3.10 이상을 설치하고 PATH 옵션을 선택하세요. 설치 후 탐색기 또는 컴퓨터를 다시 시작하세요. Microsoft Store의 실행 별칭만 있으면 Python이 설치된 것이 아닐 수 있습니다.

### 포트가 이미 사용 중입니다
사용 가능한 포트를 자동 선택합니다. 8765–8795가 모두 사용 중이면 기존 Studio 콘솔을 닫거나 다른 프로그램을 종료하세요.

### API 키가 없습니다
데모 모드는 정상입니다. 수동 편집과 저장을 사용할 수 있습니다. AI를 쓰려면 키 설정 후 앱을 재실행하세요. 인증 오류는 키를, HTTP 429는 API 잔액·요청 한도를 확인하세요.

### 이미지가 열리지 않습니다
지원 형식과 파일 용량을 확인하세요. 손상 파일, 4천만 픽셀 초과 이미지, 이름만 JPG로 바꾼 다른 형식은 변환해야 합니다.

### 프로그램 창이 바로 닫힙니다
ZIP을 완전히 풀고 `START_HERE.cmd`를 실행하세요. 실패 시 pause로 창을 유지합니다. 보안 프로그램이 파일 실행을 차단한 경우 차단 사유를 확인하세요. 관리자 권한으로 실행하지 않아도 됩니다.

### 패키지 설치 실패
인터넷·저장 공간을 확인하세요. 인증서 오류가 나면 시스템 날짜와 회사의 공식 인증서 설정을 확인하세요. TLS 검증을 끄지 마세요. 폴더를 이동해 가상환경이 깨졌다면 앱을 종료하고 `.venv`를 삭제한 뒤 실행하세요.

## 개발 및 검증

Linux/macOS: `python -m venv .venv`, `.venv/bin/python -m pip install -r requirements.txt`, `.venv/bin/python app.py --no-browser` 순서로 실행합니다. Node는 필요하지 않습니다.

테스트: `.venv/bin/python -m unittest discover -s tests -v` (Windows: `.venv\Scripts\python.exe -m unittest discover -s tests -v`).

이 배포는 Linux에서 합성·한글/공백 경로·웹 API·ZIP 테스트를 실행했습니다. **실제 Windows 10/11의 더블클릭, 사용자 계정 경로, 브라우저 자동 열기는 미검증**입니다. 실제 키를 사용한 유료 AI 요청도 수행하지 않았습니다. 배포 전에 대상 Windows 장비에서 확인하세요.
