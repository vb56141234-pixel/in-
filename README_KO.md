# 1028FALL Studio — POST SET Edition

캡처·참고 이미지에서 **Instagram Carousel 콘텐츠와 Caption을 제작하고 다운로드**하는 로컬 웹앱입니다. 프로젝트에는 독립적인 **A / B / C SET**가 있으며 각각 SOURCE 1–10장과 언어별 버전을 보관합니다. Instagram에는 사용자가 직접 업로드합니다.

## 1. 준비

1. 프로그램 ZIP을 **완전히 압축 해제**하세요. ZIP 안에서 실행하지 마세요.
2. Python **3.10 이상**을 설치하세요: <https://www.python.org/downloads/>
3. 설치 화면에서 **Add python.exe to PATH**를 선택하세요.
4. Node 설치나 관리자 권한은 필요하지 않습니다. 일반 로컬 폴더를 권장합니다.
5. 기존 버전을 사용 중이면 먼저 작업을 ZIP으로 저장하세요. 새 프로그램 폴더에 기존 `.env`를 직접 복사하거나 키 설정을 다시 실행하세요. 키 파일은 공유하지 마세요.

## 2. 실행

`START_HERE.cmd`를 더블클릭하세요. 가상환경과 패키지 설치 후 브라우저가 열립니다. 콘솔 창을 열어 두고 종료할 때 **Ctrl+C**를 누르세요. 브라우저가 열리지 않으면 콘솔의 주소를 직접 입력하세요. 기본 포트 8765가 사용 중이면 8795까지 자동 탐색합니다.

이 버전은 Linux에서 검증했습니다. **실제 Windows 10/11에서 더블클릭 실행은 미검증**입니다. 배치파일은 UTF-8/CRLF, 자체 폴더 기준 경로, 따옴표, Python 검사, 실패 시 pause를 유지합니다.

## 3. API 키 설정

최초 설치 후 앱을 종료하고 `setup_api_key.cmd`를 실행하세요. 숨김 입력으로 키를 받아 로컬 `.env`에 저장합니다. 앱을 다시 시작해야 적용됩니다. 기본 모델은 `gpt-4.1-mini`이며 `.env`의 `OPENAI_MODEL`로 변경할 수 있습니다.

키가 없으면 **데모 모드**입니다. 수동 버전 생성, 편집, 로컬 디자인/Variation, PNG·ZIP 저장과 프로젝트 복원은 가능합니다. AI 분석·문구 생성만 비활성화됩니다. OpenAI API 사용에는 별도 요금이 발생할 수 있습니다.

## 4. SOURCE 업로드

1. 왼쪽에서 A/B/C SET 중 하나를 선택하세요. 오른쪽 SET 이름을 눌러도 선택됩니다.
2. **사진 추가**, **여러 장 추가**, **폴더 업로드**로 JPG/JPEG/PNG/WEBP를 넣으세요.
3. 각 SET는 최대 10장, 각 파일은 최대 32MB·4천만 픽셀입니다. 초과·손상 파일은 오류로 안내하고 유효한 파일은 유지합니다.
4. SOURCE 썸네일을 드래그하여 순서를 바꾸세요. ×로 개별 삭제, **전체 삭제**로 현재 SOURCE 목록을 비웁니다.

SOURCE의 원본 바이트는 수정하지 않습니다. 이미 만든 언어 버전은 자신의 SOURCE 참조와 스토리 순서를 보존합니다. SOURCE 목록을 변경하면 기존 버전에 안내가 표시됩니다. 새 순서를 반영하려면 콘텐츠를 다시 생성하세요. 기존 버전에서 사용하는 삭제된 SOURCE 파일은 버전 보존을 위해 남아 있습니다.

## 5. 콘텐츠와 언어 버전 생성

1. **작성 언어**를 선택하세요: 한국어·日本語·English·Français·Español·Português·Deutsch.
2. 문체 샘플, 이미지 비율과 Variation을 설정하세요. 기본 Feed 비율은 **4:5**입니다.
3. **AI 콘텐츠 생성**을 누르면 선택 SET의 SOURCE 전체를 함께 분석하고 이미지 속 문구·주제·관계·스토리 순서를 추출합니다. 해당 언어의 SNS 문체로 HOOK 후보 5개, Carousel 문구와 SET 공통 Caption을 새로 구성합니다.
4. HOOK 후보를 선택하거나 제목·문구·Caption을 직접 수정하세요. 첫 슬라이드 제목과 HOOK은 함께 반영됩니다.
5. 언어를 바꾸고 **언어 버전 생성**을 누르세요. SOURCE를 다시 참고해 새 콘텐츠를 구성하며 기존 KO/JA/EN 등은 유지합니다. 같은 언어의 전체 재생성은 성공 시 그 언어 버전만 교체합니다.
6. SET의 KO/JA/EN 탭으로 기존 버전을 확인하세요. 작성 언어 선택은 다음 생성의 대상이며 탭 전환은 저장한 버전 보기입니다.

API 키가 없다면 **수동 버전 만들기**를 누르고 제목·문구·Caption을 입력하세요. 기존 버전이 있는 언어는 그대로 엽니다.

AI 실행은 사용자가 생성/재생성 버튼을 누를 때만 SOURCE를 OpenAI로 전송합니다. 자동 게시·Instagram 로그인·예약 게시 기능은 없습니다. 캡처 속 뉴스나 연구 주장은 사실로 검증된 것이 아니며, 외부 Web Fact Check는 아직 연결하지 않았습니다. 게시 전 사용자가 검토하세요.

## 6. 이미지 Variation과 디자인

- **언어 변경 시 이미지도 미세 변형** ON: 언어별로 zoom(최대 4%), crop 위치, 밝기·대비(±3%), 배경 blur의 작은 차이를 저장합니다. SOURCE 자체는 바뀌지 않습니다.
- OFF: 이 추가 변형을 적용하지 않습니다. 선택한 비율·맞춤·텍스트 디자인은 그대로 적용합니다.
- AI Image API는 연결하지 않았으며 현재 Variation은 **로컬 Pillow 처리**입니다. 선택적 AI 제공자 확장 지점을 분리했습니다.
- 비율: **1:1 (1080×1080), 4:5 (1080×1350), 9:16 (1080×1920)**.
- 맞춤: Crop / Fit / Background Blur. 캡처의 전체 텍스트를 보존하려면 Fit 또는 Background Blur를 선택하세요.

오른쪽 이미지를 선택하면 왼쪽 스타일 패널이 해당 슬라이드를 편집합니다. Font, 크기, Regular/Medium/Bold/ExtraBold/Black, 색상, 정렬, 위치, 행간, 자간, Shadow, Outline, 텍스트 배경 색·불투명도, Gradient 농도·범위·방향을 조정할 수 있습니다. 이미지 위에서 드래그하거나 화살표로 10px씩 이동하세요. 길이가 긴 문구는 자동 줄바꿈·축소됩니다.

**현재 버전 전체에 적용**은 같은 디자인을 해당 버전의 모든 슬라이드에 적용합니다. **새 버전 기본값 저장**은 앞으로 만들 버전의 디자인을 저장합니다. 비율·맞춤·Variation의 변경은 기본적으로 새 버전에 적용되며 **현재 버전에 비율·Variation 적용**으로 기존 버전에 적용할 수 있습니다. 각 버전의 비율과 디자인은 독립적으로 저장됩니다.

시스템 CJK 폰트를 사용합니다. Windows는 맑은 고딕, Linux는 Noto CJK를 우선합니다. 선택한 폰트·굵기가 없으면 가장 가까운 설치 폰트를 사용합니다. 모든 5개 굵기의 실제 폰트 파일을 배포하지는 않습니다. `.env`에 `STUDIO_FONT="C:/폰트 경로/폰트.ttf"`를 설정하면 해당 로컬 폰트를 사용합니다. 글자가 깨지면 해당 언어 폰트 설치 여부를 확인하세요.

로고는 PNG/WEBP를 업로드하고 전체 프로젝트 또는 A/B/C 개별 SET에 적용합니다. SET는 프로젝트 로고를 상속하거나 자체 로고를 쓰거나 로고를 표시하지 않을 수 있습니다. 로고 크기·왼쪽/중앙/오른쪽 위치·삭제를 지원합니다.

각 슬라이드의 **순서 ← / →**는 해당 언어 버전의 Carousel 순서를 바꿉니다. SOURCE 순서나 다른 언어 버전은 바뀌지 않습니다.

## 7. 개별 재생성

- HOOK 다시 생성: 후보와 첫 슬라이드 제목만 변경.
- 현재 이미지 문구 다시 생성: 선택 슬라이드 문구만 변경.
- Caption 다시 생성: 해당 버전의 Caption만 변경.
- 디자인 다시 생성: 선택 슬라이드의 배치·Gradient만 로컬에서 변경.
- Variation 다시 생성: Variation이 켜진 버전에서 해당 슬라이드의 로컬 변형만 변경.
- 현재 SET 전체 다시 생성: 현재 표시한 언어의 전체 콘텐츠를 재생성.

AI 분석/생성이 실패해도 기존 버전은 보존되며 SET에 오류를 표시합니다. 다른 SET를 선택해 계속 작업할 수 있습니다. 모든 AI 콘텐츠 재생성은 해당 버전의 SOURCE를 다시 분석합니다.

## 8. 다운로드와 프로젝트 복원

- **현재 이미지 다운로드**: 선택 이미지의 PNG.
- **현재 언어 VERSION 다운로드**: 선택 SET의 현재 탭 버전.
- **현재 SET 다운로드**: 선택 SET의 모든 언어 버전.
- **A/B/C 전체 다운로드**: 모든 SET와 모든 생성 버전.
- **프로젝트 전체 ZIP 다운로드**: 빈 SET까지 포함한 전체 작업과 SOURCE, 로고, 설정. 다른 ZIP 범위에도 해당 작업을 복원할 원본·설정을 포함합니다.
- **project.json**: 설정 메타데이터만 저장합니다. 원본 바이트는 포함하지 않으므로 JSON만으로 사진을 복원할 수 없습니다.

ZIP 구조:

```text
1028FALL_PROJECT/
  A_SET/KO/01.jpg, 02.jpg, caption.txt, content.json
  A_SET/JA/01.jpg, 02.jpg, caption.txt, content.json
  B_SET/...
  C_SET/...
  sources/원본 및 로고 파일
  project.json
```

프로그램을 종료한 뒤에도 **프로젝트 불러오기**로 ZIP을 선택하면 SOURCE·순서·언어 버전·HOOK·문구·Caption·폰트·위치·Gradient·로고·비율·Variation을 복원합니다. 최대 ZIP 용량은 업로드 및 압축 해제 기준 **2GB**, 메타데이터는 2MB입니다. 매우 큰 프로젝트는 SET별로 나누어 저장하세요.

새 버전은 로컬 작업 파일과 브라우저 세션을 유지해 같은 브라우저·같은 포트에서는 재실행 후 작업을 이어갈 수 있도록 구현했습니다. 쿠키를 삭제하거나 포트/브라우저가 달라지면 새 작업이 열릴 수 있으므로 **휴대·백업·확실한 복원은 프로젝트 ZIP을 사용하세요.**

구형 v1 ZIP도 가져올 수 있습니다. 최대 30장을 A/B/C에 10장씩 배치하고 기존 제목·본문·위치·언어를 보존합니다. 구형 1:1 결과는 1:1로 가져옵니다. 30장 초과는 분할 안내와 함께 거부하며 원본 ZIP은 변경하지 않습니다. 이전 이미지별 화면과 API는 `/legacy` 경로로 유지했습니다.

작업 파일은 `data/temp`에, 로컬 세션 서명 키는 `data/.session-key`에 저장합니다. **새 프로젝트 · 현재 작업 파일 정리**는 현재 세션의 작업·원본·언어 버전·임시파일을 지웁니다. 다른 세션까지 정리하려면 먼저 백업 후 앱을 종료하고 `data/temp`를 삭제하세요. `.env`·`data`·개인 사진은 프로그램 배포 ZIP에 포함하지 않습니다.

## 9. 오류 해결

### Python을 찾을 수 없습니다
Python 3.10 이상과 PATH 옵션을 확인하세요. Microsoft Store 실행 별칭만 있는 것은 Python 설치가 아닐 수 있습니다. 설치 후 실행기를 다시 여세요.

### 포트가 이미 사용 중입니다
자동 대체 포트를 사용합니다. 8765–8795가 모두 사용 중이면 기존 Studio 콘솔을 닫으세요.

### API 키가 없거나 AI 요청이 실패합니다
데모 모드는 정상입니다. 키 설정 후 앱을 재시작하세요. HTTP 401은 키 인증, 429는 잔액·요청 한도, 시간 초과는 연결 상태를 확인하세요. AI 모델이 이미지 입력과 JSON 응답을 지원해야 합니다.

### SOURCE를 추가했는데 기존 이미지가 그대로입니다
기존 언어 버전은 보존하기 때문에 정상입니다. 변경한 SOURCE 구성을 반영하려면 선택 언어의 콘텐츠를 다시 생성하세요. 새 버전 생성 전에는 기존 작업을 ZIP으로 저장할 수 있습니다.

### 프로그램 창이 바로 닫힙니다 / 설치 실패
압축을 완전히 풀고 실행기를 사용하세요. 실패하면 창이 유지됩니다. 인터넷·저장 공간·보안 프로그램의 차단 사유를 확인하세요. 인증서 검증을 끄지 마세요. 폴더 이동 후 가상환경이 깨지면 앱을 종료하고 `.venv`를 삭제한 뒤 재실행하세요.

## 10. 개발과 검증

Linux/macOS: `python -m venv .venv`, `.venv/bin/python -m pip install -r requirements.txt`, `.venv/bin/python app.py --no-browser`.

테스트: `.venv/bin/python -m unittest discover -s tests -v`.
Windows: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.

브라우저 검증 스크립트는 `tests/browser/`에 있습니다. 개발자가 별도 Playwright를 설치해 실행하는 선택적 검증이며 앱 사용자에게 Node는 필요하지 않습니다. 자세한 결과와 미검증 범위는 `TEST_RESULTS_KO.md`를 확인하세요.
